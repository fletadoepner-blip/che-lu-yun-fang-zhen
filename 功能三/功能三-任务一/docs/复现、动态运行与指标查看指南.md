# 任务1复现、动态运行与指标查看指南

## 1. 运行环境与版本对齐

任务1的 `src/algorithms.py`、`src/run_cityflow.py`、`src/ugat_frap.py` 与功能三任务二主线工程 `UGAT_FRAP_TRANSYT协同_雄安20路口工程` 保持逐文件一致；该工程是任务三最终消融实验的运行来源。

统一配置为：20 个受控路口；早/午/晚三时段；7500 仿真步；10 步决策间隔；单线程；随机种子 20260816；八相位动作空间；TRANSYT 周期为 9 个决策周期。为与任务三归档指标严格可比，所有正式运行必须完整执行 7500 步。

## 2. 构建镜像

在 PowerShell 进入任务1目录后执行：

```powershell
docker build --no-cache -t xiong-an-task1:cityflow-local .
```

成功标志为 Docker 构建结束且 `src/validate_scenario.py` 输出 `"status": "PASS"`。

## 3. 复现任务1三类基线

早高峰：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\run_task3_aligned_baselines.ps1 -Period morning -Steps 7500 -Threads 1 -Image xiong-an-task1:cityflow-local
```

将 `morning` 分别替换为 `midday`、`evening`，可复现三个时段。每个时段会依次生成 fixed、max_pressure、transyt 三类基线输出，目录为：

```text
结果/任务3对齐复现/<period>/<algorithm>/
```

每个算法目录包含 `metrics.csv`、`trace_<algorithm>_<period>.json`、`live_<algorithm>_<period>.jsonl` 和 `cityflow_<period>.json`。

## 4. 查看动态 TRANSYT 运行图

动态显示只允许 TRANSYT，运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\run_and_show.ps1 -Period morning -Steps 7500 -Threads 1 -LiveInterval 1 -Image xiong-an-task1:cityflow-local
```

将弹出 `Xiong'an 20-Junction CityFlow Live Monitor`。路口颜色表示当前八相位动作；窗口底部显示 `simulation time`、在网车辆数、`injected`、`queued` 和 `displayed`。动态轨迹保存到 `outputs/dynamic/`。

## 5. 一次性查看动态画面和全部指标

上面的 `run_and_show.ps1` 是集成入口：仿真期间打开完整动态 TRANSYT 窗口，结束后自动在同一 PowerShell 窗口打印 travel time、delay、throughput、queue 等指标，文件位于 `outputs/dynamic/metrics.csv`。也可查看原始 CSV：

```powershell
Get-Content .\outputs\dynamic\metrics.csv
```

字段说明：

| 字段 | 含义 | 判读方向 |
| --- | --- | --- |
| `average_travel_time_s` | CityFlow 统计的平均旅行时间（秒） | 越小越好 |
| `estimated_delay_s` | 平均旅行时间减平均自由流时间 | 越小越好 |
| `throughput_est` | 已完成车辆估计占已发车车辆比例 | 越大越好 |
| `final_queue_proxy` | 仿真末端的进口车道车辆计数代理量 | 越小越好 |
| `final_active_vehicles` | 仿真末端仍在路网内的车辆数 | 越小越好 |
| `freeflow_mean_s` | 按路径长度和最大速度计算的平均自由流时间 | 作为延误基准 |

批量基线复现生成的结果位于 `结果/任务3对齐复现/<period>/<algorithm>/metrics.csv`；该目录不存在表示尚未运行 `run_task3_aligned_baselines.ps1`。任务三的最终六组消融指标和图表位于：

```text
..\任务3_实验验证与消融对比\最终主线_UGAT_TRANSYT_FRAP\TRANSYT_FRAP消融实验汇总.csv
..\任务3_实验验证与消融对比\最终主线原始指标与轨迹\outputs\ablation_transyt\
```

`trace_*.json` 按采样时刻保存旅行时间、排队代理量和相位动作；`live_*.jsonl` 额外保存动态车辆位置，均可作为复算和审计依据。
