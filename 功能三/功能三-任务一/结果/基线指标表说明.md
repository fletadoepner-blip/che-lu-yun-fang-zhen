# 基线指标表

复算后的正式指标表由以下命令生成：

```powershell
python .\scripts\summarize_baselines.py .\结果\baseline_runs\metrics.csv --output .\结果\baseline_summary.csv
```

表字段及评价口径：

| 字段 | 含义 |
| --- | --- |
| `throughput_est` | 已完成车辆估计值除以截至仿真末端已发车车辆数。 |
| `average_travel_time_s` | CityFlow 在仿真末端给出的平均旅行时间（秒）。 |
| `estimated_delay_s` | 平均旅行时间减去相同车辆路径与最大速度计算的平均自由流时间（秒）。 |
| `final_queue_proxy` | 仿真末端四向进口车道计数之和，仅作为排队的统一代理指标。 |

该表仅汇总同一协议下的原始 `metrics.csv`，不修改或推断任何运行数值。
