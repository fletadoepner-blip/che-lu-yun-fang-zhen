# 功能三任务二提交材料索引

## 最终主版本

- 主版本唯一标识：`UGAT+FRAP+TRANSYT 协同控制器`。
- 正式工程目录：`UGAT_FRAP_TRANSYT协同_雄安20路口工程/`。
- 运行算法参数：`ugat_frap_transyt`；该参数在每个决策周期只向 CityFlow 下发一个八相位动作。
- 版本、依赖、模型、数据和结果的锁定信息见 `版本锁定清单.md`。

## 验收操作

在 `UGAT_FRAP_TRANSYT协同_雄安20路口工程/` 中执行：

```powershell
python .\src\validate_scenario.py
docker build -t xiong-an-20-platform:final .
docker run --rm xiong-an-20-platform:final --period morning --algorithm ugat_frap_transyt --steps 7500 --threads 4
```

静态校验确认 20 个受控路口、拓扑、流量、路线及模型参数；正式运行在 `outputs/metrics.csv` 写入指标，并在 `outputs/trace_ugat_frap_transyt_morning.json` 输出每个控制周期的信号动作和队列代理量。
