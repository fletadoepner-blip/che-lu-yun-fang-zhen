                                    一.单路口frap

                        ┌──────────────────────────┐
                        │      开始 (Epoch)        │
                        └─────────────┬────────────┘
                                      │
                                      ▼
                        ┌──────────────────────────┐
                        │  获取当前路口状态         │
                        │  - 各车道排队长度 (12维)  │
                        │  - 当前相位 (one-hot)     │
                        └─────────────┬────────────┘
                                      │
                                      ▼
                        ┌──────────────────────────┐
                        │  Step 1: 相位需求建模    │
                        │  对每个相位:              │
                        │  输入: 相位嵌入 + 车道排队│
                        │  输出: 相位需求表示       │
                        └─────────────┬────────────┘
                                      │
                                      ▼
                        ┌──────────────────────────┐
                        │  Step 2: 相位对嵌入      │
                        │  将相位两两组合成"相位对"│
                        │  每个相位对 = 两个相位    │
                        │  需求表示的"和"           │
                        └─────────────┬────────────┘
                                      │
                                      ▼
                        ┌──────────────────────────┐
                        │  Step 3: 相位竞争        │
                        │  ┌────────────────────┐  │
                        │  │  竞争掩码 (comp_mask)│ │
                        │  │  标记哪些相位冲突   │  │
                        │  └─────────┬──────────┘  │
                        │            ▼             │
                        │  ┌────────────────────┐  │
                        │  │  相位对竞争卷积   │  │
                        │  │  学习冲突关系     │  │
                        │  └─────────┬──────────┘  │
                        └─────────────┬────────────┘
                                      │
                                      ▼
                        ┌──────────────────────────┐
                        │  Step 4: 相位得分 (Q值)  │
                        │  对每个相位输出一个 Q 值 │
                        │  Q = 该相位所有竞争结果  │
                        │      的聚合              │
                        └─────────────┬────────────┘
                                      │
                                      ▼
                        ┌──────────────────────────┐
                        │  Step 5: 动作选择        │
                        │  选择 Q 值最大的相位执行 │
                        │  采用 ε-greedy 策略探索  │
                        └─────────────┬────────────┘
                                      │
                                      ▼
                        ┌──────────────────────────┐
                        │  执行相位切换             │
                        │  (持续 action_interval 秒)│
                        └─────────────┬────────────┘
                                      │
                                      ▼
                        ┌──────────────────────────┐
                        │  收集反馈                 │
                        │  - 奖励 (负排队长度)     │
                        │  - 下一状态              │
                        └─────────────┬────────────┘
                                      │
                                      ▼
                        ┌──────────────────────────┐
                        │  DQN 训练更新            │
                        │  - 经验回放              │
                        │  - TD 误差最小化         │
                        └─────────────┬────────────┘
                                      │
                                      ▼
                        ┌──────────────────────────┐
                        │      结束 (下一时间步)    │
                        └──────────────────────────┘
                                                   二.多路口frap

┌─────────────────────────────────────────────────────────────────────────────────────┐
│                               第一级：路口级 FRAP                                  │
│                           (每个路口独立运行，共 N 个)                              │
│                                                                                     │
│  ┌─────────────────┐  ┌─────────────────┐        ┌─────────────────┐              │
│  │    路口 1 FRAP   │  │    路口 2 FRAP   │  ...  │    路口 N FRAP   │              │
│  │  ┌─────────────┐ │  │  ┌─────────────┐ │        │  ┌─────────────┐ │              │
│  │  │ 局部观测     │ │  │  │ 局部观测     │ │        │  │ 局部观测     │ │              │
│  │  │ (本路口排队) │ │  │  │ (本路口排队) │ │        │  │ (本路口排队) │ │              │
│  │  └──────┬──────┘ │  │  └──────┬──────┘ │        │  └──────┬──────┘ │              │
│  │         ▼        │  │         ▼        │        │         ▼        │              │
│  │  ┌─────────────┐ │  │  ┌─────────────┐ │        │  ┌─────────────┐ │              │
│  │  │ 相位竞争DQN │ │  │  │ 相位竞争DQN │ │        │  │ 相位竞争DQN │ │              │
│  │  │ (FRAP网络)  │ │  │  │ (FRAP网络)  │ │        │  │ (FRAP网络)  │ │              │
│  │  └──────┬──────┘ │  │  └──────┬──────┘ │        │  └──────┬──────┘ │              │
│  │         ▼        │  │         ▼        │        │         ▼        │              │
│  │  输出: 动作 a1   │  │  输出: 动作 a2   │        │  输出: 动作 aN   │              │
│  └─────────────────┘  └─────────────────┘        └─────────────────┘              │
│         │                        │                         │                      │
│         └────────┬───────────────┴──────────────┬──────────┘                      │
│                  ▼                               ▼                                 │
│         执行相位切换 (局部)           上报第一级状态给第二级                          │
│         (action_interval 秒)          (排队、相位、吞吐量)                          │
└─────────────────────────────────────────────────────────────────────────────────────┘
                                        │
                                        │ 全局状态: [排队1..排队N, 相位1..相位N, 吞吐量]
                                        ▼
┌─────────────────────────────────────────────────────────────────────────────────────┐
│                              第二级：全局协调器                              │
│                                                                                     │
│  ┌─────────────────────────────────────────────────────────────────────────────┐   │
│  │                          输入: 全局状态向量                                 │   │
│  │  [ 路口1排队, 路口1相位, 路口2排队, 路口2相位, ... 路口N排队, 路口N相位 ]   │   │
│  │  维度: N × (车道数 + 相位数)                                              │   │
│  └─────────────────────────────────┬───────────────────────────────────────────┘   │
│                                    │                                               │
│                                    ▼                                               │
│  ┌─────────────────────────────────────────────────────────────────────────────┐   │
│  │  Step 1: 区域拥堵检测                                                       │   │
│  │  - 计算区域平均排队长度                                                      │   │
│  │  - 检测是否有路口排队超过阈值 (阈值=15辆)                                   │   │
│  │  - 检测吞吐量是否连续下降                                                   │   │
│  └─────────────────────────────────┬───────────────────────────────────────────┘   │
│                                    │                                               │
│                                    ▼                                               │
│  ┌─────────────────────────────────────────────────────────────────────────────┐   │
│  │  Step 2: 全局状态编码 (Encoder)                                             │   │
│  │  - 将所有路口状态拼接，通过 MLP 编码为固定长度向量                          │   │
│  │  - 保留空间关系                                      │   │
│  └─────────────────────────────────┬───────────────────────────────────────────┘   │
│                                    │                                               │
│                                    ▼                                               │
│  ┌─────────────────────────────────────────────────────────────────────────────┐   │
│  │  Step 3: 全局决策网络                                              │   │
│  │  ┌────────────────────────────────────────────────────────────────────────┐ │   │
│  │  │  前向模型: 预测"在当前全局状态下，执行某协调动作后的全局下一状态"      │ │   │
│  │  └────────────────────────────────────────────────────────────────────────┘ │   │
│  │  ┌────────────────────────────────────────────────────────────────────────┐ │   │
│  │  │  逆模型: 反推"要达到目标全局状态，应该下发什么协调指令"               │ │   │
│  │  └────────────────────────────────────────────────────────────────────────┘ │   │
│  │  ┌────────────────────────────────────────────────────────────────────────┐ │   │
│  │  │  不确定性量化: 判断当前协调指令的可信度                                │ │   │
│  │  └────────────────────────────────────────────────────────────────────────┘ │   │
│  └─────────────────────────────────┬───────────────────────────────────────────┘   │
│                                    │                                               │
│                                    ▼                                               │
│  ┌─────────────────────────────────────────────────────────────────────────────┐   │
│  │  Step 4: 输出协调信号 (3种类型)                                            │   │
│  │                                                                             │   │
│  │  类型A - 相位偏移建议 (精细调节)                                           │   │
│  │    对每个路口输出一个偏移量 (-5s ~ +5s)，调整绿灯开始时间                   │   │
│  │    适用: 轻微拥堵，形成绿波                                                 │   │
│  │                                                                             │   │
│  │  类型B - 探索率调整 (中观调节)                                             │   │
│  │    增加/减少每个路口的 ε-greedy 探索率                                     │   │
│  │    适用: 路况变化期，需要更多探索                                           │   │
│  │                                                                             │   │
│  │  类型C - 紧急干预 (强制控制)                                               │   │
│  │    直接覆盖特定路口的动作 (如: 强制放行拥堵方向)                           │   │
│  │    适用: 严重拥堵，局部策略失效                                             │   │
│  └─────────────────────────────────┬───────────────────────────────────────────┘   │
│                                    │                                               │
└────────────────────────────────────┼───────────────────────────────────────────────┘
                                     │
                                     │ 协调信号下发
                                     ▼
┌─────────────────────────────────────────────────────────────────────────────────────┐
│                              反馈到第一级执行                                       │
│                                                                                     │
│  ┌─────────────────────────────────────────────────────────────────────────────┐   │
│  │  第一级收到协调信号后:                                                       │   │
│  │  - 类型A: 在FRAP输出的动作上叠加偏移量 → 执行调整后的相位                    │   │
│  │  - 类型B: 修改 epsilon 值 → 后续决策的探索程度改变                           │   │
│  │  - 类型C: 直接跳过FRAP决策 → 执行强制相位                                    │   │
│  └─────────────────────────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────────────────────────┘
                                     │
                                     │ 执行后，下一轮状态反馈给第二级
                                     ▼
