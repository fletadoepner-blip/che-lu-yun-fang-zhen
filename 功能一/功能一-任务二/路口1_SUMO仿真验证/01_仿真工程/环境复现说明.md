# 环境复现说明

本目录不包含某一台电脑上的 Python、Conda、SUMO 可执行文件或个人路径。比赛交付应提交代码、数据、场景、结果和以下复现步骤，不需要提交本机运行环境文件夹。

## 最低环境要求

- Python 3.10 或更高版本
- SUMO 1.19 或更高版本，包含 `sumo`、`sumo-gui`、`netconvert`
- Python 包：见 `requirements.txt`

## 新电脑部署

```powershell
cd "01_仿真工程"
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r .\requirements.txt
```

安装 SUMO 后，任选一种方式让程序找到 SUMO：

```powershell
# 方式一：设置 SUMO_HOME
$env:SUMO_HOME='C:\Program Files\Eclipse\Sumo'

# 方式二：将 SUMO 的 bin 目录加入系统 PATH
```

验证环境：

```powershell
python .\run_experiment.py --mode fixed --duration 60
```

完整实验与图表：

```powershell
python .\run_experiment.py --mode both --duration 7200
python .\plot_comparison.py
```

## 当前电脑的 PyCharm

当前电脑中的 `.venv` 使用 Python 3.14 预览版，NumPy DLL 加载不稳定，不建议用于本工程。请在 PyCharm 的 `Settings > Project > Python Interpreter` 选择已验证的 `project1` 环境，或创建新的 Python 3.10+ 虚拟环境后按本说明安装依赖。

当前电脑可选解释器：`C:\Users\lauri\anaconda3\envs\project1\python.exe`。

在其他电脑上，请按“新电脑部署”创建环境。启动 BAT 会优先使用当前电脑存在的 `project1`，否则调用系统 `python`；也可预先设置 `PYTHON_EXE` 环境变量指定解释器。
