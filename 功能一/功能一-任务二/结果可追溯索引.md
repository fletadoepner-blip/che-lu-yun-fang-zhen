# 结果可追溯索引

| 输出 | 原始来源 | 关键参数 |
|---|---|---|
| `results/metrics_fixed.json` | `scenario/dataset_1.net.xml`、`dataset_1.rou.xml`、`dataset_1.add.xml`、`tripinfo_fixed.xml` | mode=fixed, seed=42, duration=7200 |
| `results/metrics_adaptive.json` | 同上，控制逻辑来自 `run_experiment.py` | mode=adaptive, gain=-44, seed=42, duration=7200 |
| `results/summary.csv` | 上述两个 metrics JSON，由 `汇总结果.py` 生成 | 字段与 JSON 一一对应 |
| `results/performance_comparison.png/pdf` | 当前提交版 PNG 图表；数值对应 `metrics_fixed.json` 与 `metrics_adaptive.json` | 四项指标、改善率；PNG 为最新提交图 |
| `verify_results.py` 的通过日志 | 两份 metrics JSON | 等待时间有效、完成车辆不下降、旅行时间改善至少 10% |
| `results/tripinfo_fixed.xml` | SUMO `--tripinfo-output` 固定配时运行 | 车辆级明细 |
| `results/tripinfo_adaptive.xml` | SUMO `--tripinfo-output` 自适应运行 | 车辆级明细 |

场景输入由 `prepare_dataset1_scenario.py` 从 `scenario/demo_1_流量和配时方案.xlsx` 生成。固定与自适应运行共用同一场景、流量、相位顺序和随机种子；仅 `adaptive` 在相位开始时调用 `setPhaseDuration`。

推荐运行入口为任务根目录的 `run_task2.ps1` 和 `run_task2.bat`。PowerShell 方式应执行 `& ".\run_task2.ps1"`，不得逐行粘贴脚本内容。入口采用全 ASCII 文件名和内容，以兼容 Windows PowerShell 编码设置。

最新性能对比图已同步覆盖至 `results/performance_comparison.png`，并嵌入提交说明报告。图中数值与两个 metrics JSON 及 summary.csv 保持一致。
