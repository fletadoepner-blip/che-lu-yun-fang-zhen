# 接口协议、字段字典与时序

## 字段字典

| 字段 | 类型 | 单位/范围 | 含义 |
|---|---|---|---|
| `time_s` | number | 秒，>=0 | 当前仿真时间 |
| `intersection_id` | string | SUMO TLS ID | 路口唯一标识 |
| `phase` | integer | >=0 | 信号相位编号 |
| `phase_duration_s` | number | 秒，>=0 | 当前相位持续时长 |
| `queue_length` | integer | 辆，>=0 | 受控车道排队数合计 |
| `vehicle_count` | integer | 辆，>=0 | 车道当前车辆数 |
| `queue_count` | integer | 辆，>=0 | 车道停止车辆数 |
| `speed_mps` | number | m/s | 车道平均速度 |
| `occupancy_pct` | number | 百分比 | 车道占有率 |
| `duration_s` | number | 秒，>0 | 动作的可选相位保持时长 |

## 控制时序

```text
算法客户端             接口服务 / TraCI                    SUMO
    | POST /start             |                              |
    |------------------------>| traci.start                  |
    |<-----路口 ID 列表--------|<-----------------------------|
    | GET /state              | 读取 lane / trafficlight     |
    |------------------------>|----------------------------->|
    |<------观测 JSON---------|<-----------------------------|
    | POST /action            | setPhase / setPhaseDuration  |
    |------------------------>|----------------------------->|
    | POST /step              | simulationStep               |
    |------------------------>|----------------------------->|
    |<------新时间------------|<-----------------------------|
```

## 约束与异常

1. 未启动会话就查询、动作或步进时返回 HTTP 409。
2. 未知路口、字段缺失、非法步骤范围返回 HTTP 400 或 404。
3. 每个算法循环应执行“状态 -> 动作 -> 步进”；动作只对本次会话有效。
4. `POST /close` 必须在实验或异常处理的 `finally` 分支调用。
5. 真实车路云接入时应增加设备身份、时间戳单调性校验、速率限制和审计日志；本包仅用于仿真联调。
